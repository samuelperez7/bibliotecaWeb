# Sistema de Gestión de Biblioteca

Proyecto web desarrollado en PHP y MySQL para la gestión de préstamos y ejemplares de una biblioteca.

## 🚀 Características
- Gestión de ejemplares y libros.
- Sistema de login y permisos para clientes y bibliotecarios.
- Registro de préstamos.

## 🛠️ Instalación local
1. Clona este repositorio en tu servidor local (`htdocs` de XAMPP).
2. Importa el archivo `biblioteca.sql` en phpMyAdmin.
3. Configura los archivos dentro de la carpeta `/conexion` con tus credenciales de MySQL. (recomendación: usar los usuarios "cliente" y "bibliotecario")
4. Accede desde tu navegador a `http://localhost/bibliotecaWeb`.
